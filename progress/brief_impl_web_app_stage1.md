## Inherited findings — acceptance criteria for this stage (each named **avoided** or **recurred** in your record, with the #8/#7 citation)

1. **#7: every page's error text was silently generic** for the app's whole life, because the field each page read was always `undefined`; four reviews walked past it. Rule: an error test asserts **the server's own words** on screen, never "an error element is present".
2. **#8 B1:** a site that shows a fixed sentence instead of the problem document (the catalogue notice), defended by a test that said "only the failure matters here, not its words".
3. **#8 RR2 D1/D2:** a *syntax* guard over error sites was defeated by the plainest shapes (`if (q.isError) return …`, `switch`, an error-boundary file) and by a proof case satisfied by incidental lines. The coordinator replaced the instrument with a **behavioural sweep**. Build the behavioural sweep **from the start** — do not build a syntax guard first.
4. **#8 RR3 D1:** a BFF route that makes **two** upstream calls (login: `POST /auth/login`, then `GET /auth/me`) dropped the problem body on the second — on the no-JavaScript form path only (the JS path relayed it). The sweep's unit is **every upstream call each BFF route makes**, discovered by observe-then-fail-each against an all-success fake Gateway, never a hand-picked call.
5. **#8 RR3 D2 / G1:** "never a generic message" is the claim's second half: in every failing run, the text the failure adds, minus the text containing the sentinel, must be a subset of a **reviewed literal** label set, checked both ways (a listed label no run produces is stale).
6. **#8 RR3 D3 / G2–G4, G6:** populations keyed on the wrong unit. (a) Interaction-gated reads and second consumers of a mutation must be in a population (a derived-vs-literal table of consumers fails loudly on a new one); (b) the settle window must outlast the longest non-poll timer the app sets, or disclose its bound; (c) the failing status is drawn from the statuses `openapi.yaml` declares for that operation, not one or two fixed statuses.
7. **#8 RR4 / probe:** the relay clears the session cookie on **401 only** — #8's reviewer killed a mutant clearing it on every 4xx/5xx; guard both directions.
8. **#8 L1:** a leader-side `.env.example` `WEB_PORT` value defeated the documented override. The leader writes `.env.example` for this stage; you report the settings you read, their defaults and their source, and you make sure nothing in `apps/web` hard-codes 3000.
9. **#8 id 98's precondition:** a 401 from **any** BFF call sends the user to `/login` (#8 `providers.tsx` `redirectOnSignedOut`) — build that path here (stage 2 builds 98 itself on the order page).
