## Decisions

- **Loop scope:** `asyncio_mode = "auto"`, default fixture and test loop scope `function`; reason written beside it in pyproject (no engine/pool outlives its loop; wider scope only via explicit `loop_scope=` on the fixture, disposed in that scope).
- **Warnings:** `error::DeprecationWarning` plus one targeted filter `ignore:The @wait_container_is_ready decorator is deprecated:DeprecationWarning:testcontainers`. Measured under `-W error::DeprecationWarning`: `import testcontainers.community.nats` raises `DeprecationWarning: The @wait_container_is_ready decorator is deprecated and will be removed in a future version. Use structured wait strategies instead: ...`. So the filter is needed; arms WP2/WP3 prove it is effective and module-specific.
- **import-linter:** `include_external_packages = true`; wildcard `otc_*.domain` is rejected by import-linter ("A wildcard can only replace a whole module"), so the forbidden contract lists the seven `otc_<s>.domain` explicitly (a source module covers nested subpackages) and `test_import_contract_coverage.py` asserts the lists equal the directories under `services/` (arm V4). Separate forbidden contract for `otc_shared_kernel`. `otc_cqrs` is in both forbidden lists.
- **Layers encoding:** `presentation > infrastructure > application > domain` per service. Infrastructure sits above application because it implements application ports, and below presentation because presentation reaches adapters only via the composition root. Forbidden consequently: application->infrastructure/presentation, infrastructure->presentation, domain->anything above. Presentation->infrastructure is permitted (a deliberate consequence; the siblings `presentation | infrastructure` encoding would break the moment `presentation -> composition -> infrastructure` exists, since import-linter counts indirect chains). Not `exhaustive`, so a top-level `composition.py` is allowed.
- **AST guard:** walks the AST, so a `/`, `float` or `decimal` in a comment, string, raw string, triple-quoted string or docstring is NOT a violation; real code inside `if TYPE_CHECKING:` and `if False:` IS flagged (a `float` annotation or dead `/` is still the wrong type in the domain). Flags: float literals (incl. `1e3`), any `Name float` (call, annotation, `isinstance`; stricter than the brief, feature 7 must use `type(x) is int`-style checks or amend), `/` and `/=`, `operator.truediv`, `import decimal` (incl. alias), `from decimal import ...` (incl. star), `importlib.import_module("decimal")` / `__import__("decimal")`, string annotations (`x: "float"`). `//` allowed. 18 must-detect and 8 must-not-detect sentinel snippets are parametrised tests.
- **Coverage:** `source` = directories (not `source_pkgs`): with `source_pkgs`, `otc_shared_kernel` was reported "never imported" and silently left out of the denominator. `fail_under = 60` in pyproject; pytest-cov enforces it.
- **Domain >=80% gate: NOT implemented, marked TODO(feature 7) in `quality.sh` section 6b.** Measured: domain files are docstring-only (0 statements), `coverage report --fail-under=80` over them passes vacuously at 100%, so a gate would be fake. Section 6b prints the number and does not gate.
