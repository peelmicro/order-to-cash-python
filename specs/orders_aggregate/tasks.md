## 7. Traps

1. **Restoring with `git checkout`.** Every file is untracked while in flight; it restores nothing. Copy-backup, always.
2. **Stale bytecode after a restore.** Clear `__pycache__` and `.mypy_cache` before the confirming run.
3. **Testing T-1 against `LEGAL_EDGES`.** A test that reads the constant proves the constant equals itself. Transcribe.
4. **`StrEnum` or `auto()` for the vocabularies.** `auto()` derives tokens from member names; `StrEnum` lets a raw row string pass a membership test unparsed.
5. **`money + other` instead of `money.add(other)`.** The dunders are typed `object`; `mypy` will not see a wrong operand.
6. **A `list` field on a frozen dataclass.** Frozen does not reach inside it.
7. **A naive `datetime` in a fixture.** It type-checks; use the conftest's aware instants.
8. **Asserting only that something raised.** Assert the `code`: R7's guard order, O2's flavour and the load checks are all visible only through it.
9. **Arming the silent-edge guard on the same edge everywhere.** Choose a different edge from the report's.
10. **Re-deciding something §3 of `requirements.md` or the ledger settled.** If one looks wrong, stop and report; a silent divergence is a parity break the benchmark cannot see.
