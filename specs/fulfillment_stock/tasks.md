# Tasks — `fulfillment_stock` (feature 17)

> Ordered; tests sit **inside** the loop, beside the code they prove. Tick a box only when the thing exists and, where it names a test, that test has been observed green. Stop at the first task you cannot complete honestly.
>
> **`[ARM]`** marks every task whose prose asserts a count, an identity, an ordering or an absence — including "exactly one", "zero rows", "never", "only after", "before", "waits", "equals the supplied", "no second". The mark follows the claim, not a sense of danger: an unflagged task that turns out to make such a claim is a guard too, and is armed the same way. A guard is not done until it has been seen to fail under the mutation the task names, following CLAUDE.md's arming protocol: `cp` a backup **into the repo-local `.arm/`** with its `sha256` recorded, introduce the one violation, run the **one** named test (a timeout kills the whole process group), record the failure verbatim in `progress/impl_fulfillment_stock.md` (its message must name the claim), restore from the backup (never `git checkout`), confirm with `cmp`, delete `__pycache__` under `services/fulfillment/src` and `.mypy_cache`, re-run green. **One mutation per claim**: a mutation that dies at an earlier assertion than the one the task is about arms nothing about that assertion. **Negative assertions need a control row** in the same test (an emitting call whose row is seen). **Name the revert**: each arm says what fails if the fix is reverted. Arms go stale when a later task changes the path: re-run them in L1, do not re-read them.
>
> **Defeat list** (CLAUDE.md): rows 1 (delete), 2 (corrupt a supplied field), 3 (substitute a sibling identifier: subjects, topic, statuses, reasons, codes, the queue group), 7 (drop an optional element: `retailerCode`, `details`), 8 (literal-to-literal: an expected value read back from the code under test), 9 (stale premise: a wait satisfied by an earlier row), 12 (a path the population never drives: the release pre-read, the no-carrier branch, the exhausted re-run) apply throughout; rows 4 – 6, 10 and 11 apply to the parity and census instruments (C3, D9, G5, G8, J1) and are armed there.
